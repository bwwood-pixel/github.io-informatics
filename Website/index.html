HTML gives structure to the internet

HTML is a markup language for documents designed to be displayed in a web browser. It defines both the structure and content of web pages.

It uses tags enclosed in angle brackets like <p> for paragraphs or <h1> for main titles.

It works with an opening tag and a closing tag (which includes a slash, like </p>) to wrap around content. On the left, you can see the actual HTML code that's generating what you're seeing here. Even this text is wrapped in paragraph <p></p> tags.

HTML tags support multimedia formats like audio, video, and, naturally, other pages on the internet.

Tags also tell a browser how to display things.
